Page: /register · Story: FE-A-001 · Owner: person-a

API calls

POST /api/v1/auth/register

Body: {email, displayName, password} → 201 {accessToken, refreshToken, user}

Note: first/last name are UI-only

Concatenated into displayName before sending. Backend only stores displayName.

Validation rules

• Email: valid format, checked on blur
• Display name: 2–32 chars, no spaces allowed
• Password: min 8 chars, strength meter updates live
• Confirm: must match password, checked on blur
• All fields validated before submit enabled

Error states

• DUPLICATE_RESOURCE (409) → "Email already registered. Sign in instead."
• Invariant I1: unique email enforced by DB UNIQUE constraint
• Password mismatch → inline red text below confirm field

Post-registration flow

1. Store accessToken + refreshToken in localStorage
2. Redirect to /events (not a dashboard — direct to value)
3. Navbar now shows avatar + "My Team" link

Password strength meter states

WeakShort / no variety
FairAdd numbers or symbols
StrongGood to go
