Page: /login · Story: FE-A-001 · Owner: person-a

API calls on this page

POST /api/v1/auth/login

Body: {email, password} → Returns {accessToken, refreshToken, user}

State transitions

• Submit → spinner on button, disabled
• 401 error → red error box above submit button
• Success → store tokens → redirect to /events
• Already logged in → redirect to /events immediately

Error states

• UNAUTHORIZED → "Invalid email or password"
• RATE_LIMITED → "Too many attempts. Try again in 30s."
• Network error → "Connection failed. Check your internet."
• Validation: email format check before submit

Accessibility notes

• Tab order: Email → Password → Forgot link → Submit
• Error message: role="alert" for screen readers
• Submit button: aria-busy="true" while loading
• No autofocus on mobile (avoids keyboard jump)
Note: No "Sign in with Google" — custom JWT only per MASTER-CONTEXT.md invariants.
